Стан виконання для Порталу

  • «виконано» → Виконано; «частково виконано» → Частково виконано.
  • Інші стани: якщо строк заходу — конкретна дата пізніше кінця звітного періоду → Строк виконання заходу не настав; інакше → Не виконано.
  • Фактичний строк: для постійних і періодичних заходів зі станом «Виконано» — остання дата звітного періоду; для решти — внесена фактична дата.
  • Опис результату для стану «Строк виконання заходу не настав» у звіт не потрапляє.

Рівень ризику

Бал = ймовірність (1–4) × наслідки (1–4). 1–2 — низький, 3–4 — середній, 6–9 — високий, 12–16 — критичний.

Шлях до цілі = (базове − поточне) / (базове − цільове) значення індикатора стану ризику.

Внесення й погодження

  • Виконавець вносить інформацію лише щодо власних заходів і подає її на погодження.
  • Координатор погоджує або повертає на доопрацювання; повернення — лише з коментарем.
  • Після подання виконавець не може змінити інформацію, доки її не повернуть.
  • Підтвердні матеріали не змінюються й не видаляються; для кожного зберігається SHA-256.
  • Перенесення строку — внутрішнє рішення координатора; строк у програмі не змінюється.
  • Нагадування: строк минув або настає протягом {{ rules.DUE_SOON_DAYS }} днів, а захід не виконано.
