# SSH-обробник ручного CD

`scripts/deploy-ssh-gate.sh` призначений для запуску через
обмежений SSH-ключ. Він приймає команду `deploy <повний SHA>`.

Шляхи до репозиторію, env-файлу, каталогу резервних копій та назва
Compose-проєкту задаються фіксованими аргументами серверної
SSH-команди, а не командою від клієнта.

Обробник дозволяє лише останній відомий коміт `origin/main` після
`git fetch`, створює окремий worktree та запускає з нього
`scripts/deploy.sh`. Після успіху worktree видаляється; після помилки
залишається для перевірки.

Запуски обробника використовують `.cd-gate.lock`, а `deploy.sh` —
`.deploy.lock` у каталозі резервних копій. Ручні та CD-розгортання
потрібно узгоджувати між собою.

Перевірка CI виконується GitHub Actions; сам SSH-обробник її не
виконує. Ключ запускає процес від імені серверного користувача, який
має доступ до Docker, тому його потрібно берегти як привілейований.
Автоматичного rollback немає.
