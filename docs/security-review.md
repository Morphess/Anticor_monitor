# Базова перевірка безпеки релізу

Проведено 20.11.2026 на локальних синтетичних даних. Це базовий огляд
коду й негативні API-тести, а не повний зовнішній penetration test.
На production сканування й експлуатація не виконувались.
Продуктові загрози та маніпуляції показниками — в [abuse-analysis.md](abuse-analysis.md).
Це датований огляд релізу, не сертифікат безпеки або новий повний аудит кожного коміту.

## Виправлено

- Створення, зміна, видалення й версії наказів більше не доступні анонімно:
  весь реєстр вимагає ADMIN. Виконавець і координатор користуються своїм
  авторизованим Execution API; доступ до чужого подання закритий.
- CORS — явний список origin, без wildcard та credential sharing;
  сервер може налаштувати JSON-перелік CORS_ORIGINS. Same-origin HTTPS
  через Tailscale не вимагає окремого CORS-дозволу.
- Нові звіти — приватні файли 0600, випадкові ключі, атомарний запис,
  SHA-256; traversal і symlink відхиляються. Помилка сховища не розкриває шлях.
- JSON-снапшоти піврічних звітів створюються з правами 0600.
- З Docker context виключено env, секрети, pycache, резервні копії й логи.
  Реальні env, node_modules, venv та runtime uploads не відстежуються.

## Перевірено

- SQLAlchemy використовує параметризовані запити. Динамічний SQL у
  міграційній репетиції використовує тільки імена таблиць із introspection
  та quoting, а не клієнтський ввід. SQL-подібний анонімний payload не
  обходить авторизацію. NoSQL-сховища в застосунку немає.
- JWT перевіряє exp/sub та фіксований алгоритм HS256; паролі хешуються Argon2.
- Вхідні контракти Pydantic відхиляють зайві поля, некоректні строки,
  оцінки й формати. Статуси ризиків захищені також CHECK/FK/trigger у БД.
- UI вставляє висновок моделі через textContent; HTML-експорти екранують
  дані через html.escape; новий risk-reassessment шаблон застосовує esc.
  Браузерні сценарії використовують реальний API без підміни авторизації.
- Пошук типових приватних ключів, GitHub/AWS/Ollama/Tailscale-подібних
  токенів у доступних об'єктах історії main/backend_v2: збігів не знайдено
  (1172 об'єкти, включно з деревами/комітами; перевірялись blob-вмісти).
  Це перевірка форматів, а не доказ відсутності всіх можливих секретів.
