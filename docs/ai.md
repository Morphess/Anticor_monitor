# Використання ШІ

ChatGPT використовували для обговорення архітектури проєкту,
підготовки правил роботи з AI-агентами та планування налаштування GitHub.

Цей файл доповнюємо під час розробки. Для кожного нового випадку
зазначаємо інструмент, задачу та як команда перевірила результат.

Claude (Anthropic, США) використовували для розбору завдання й набору організаторів та для написання
бекенду: модель даних, імпорт набору, модуль правил (сигнали RF1–RF7, стан для Порталу, рівень ризику),
процес внесення й погодження, сторінки Jinja2, автотести, чернетка `docs/backend.md`.
Як перевіряли: автотести (`backend/tests`), зокрема звірка з ключем організаторів — 29 очікуваних сигналів
і 50 рядків еталонного звіту; ручна перевірка сторінок у браузері. *(Команда: допишіть, хто й що перевіряв.)*

У ШІ-сервіси передавали лише текст завдання та синтетичний набір організаторів; службової інформації
й персональних даних реальних людей не передавали.

У самому продукті ШІ немає: усі висновки рахуються за явними правилами (`backend/app/services/rules.py`),
рішення про погодження ухвалює координатор.
