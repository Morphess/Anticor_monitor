# Як працюємо 

1. Обери Issue на дошці GitHub Projects. Перед початком звір відповідального, межі задачі та критерії готовності. Перенеси задачу в In Progress.
2. Створи окрему гілку від актуальної `main`. Додавай номер Issue до назви, наприклад `feat/12-review-queue` або `docs/5-readme`.
3. Працюй у межах задачі. Якщо зміна зачіпає файли, над якими вже працює інший учасник, узгодь її в Issue. Якщо використовуєш AI-агента, передай йому `AGENTS.md` і текст Issue.
4. Переглянь зміни, виконай доречні перевірки та відкрий PR у `main`. Опиши зміни й спосіб перевірки. Додай `Closes #12`, якщо PR повністю закриває Issue №12. Перенеси задачу в Review.
5. Після одного схвалення від іншого учасника та успішного CI виконай Squash and merge. Після злиття перевір, що Issue закрито, і перенеси задачу в Done.
